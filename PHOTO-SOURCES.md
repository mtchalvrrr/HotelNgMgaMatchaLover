# Matcha Lover photography and icon sources

## Hotel photography

The homepage, guest and manager banners, and room cards use the resort image supplied by the repository owner. The unmodified source image is stored at `mtchlvr-hotel-final/mtchlvr-hotel/src/main/resources/static/images/mtchlvr-resort.jpg`; its visible credit mark is retained. The photographer and usage license were not supplied with the image, so confirm publication rights before production use.

## Icons

The interface primarily uses text glyphs and CSS-drawn decorative elements rather than third-party icon files.
